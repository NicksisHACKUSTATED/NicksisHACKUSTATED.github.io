# Touch - HackTheBox
## Overview
Touch presented an airport self-service kiosk backed by a Windows system, a Nex(i)on DeviceHub management interface, and a MySQL database. The interesting part wasn't a single flashy exploit: it was how a collection of weak operational practices chained together. An unauthenticated API leaked device information, the device's default password allowed access to a management dashboard, and that dashboard exposed additional credentials. Once inside Windows, application files disclosed database credentials, including a privileged account password in a maintenance batch script. Finally, a MySQL User-Defined Function (UDF) was used to execute operating-system commands and read the Administrator flag.

## Recon
Started off with an `Nmap` scan to search for open ports and services.
```bash
nmap -sVC -p- -v -O -o scan.txt <machine_ip>
```
<img width="1644" height="639" alt="scan" src="https://github.com/user-attachments/assets/64f6b858-627c-4577-a038-2960c89a0c71" />

The scan identified TCP `135 (MSRPC)`, `3389 (RDP)`, `5985 (Microsoft HTTPAPI)`, and `8443 (HTTP management interface)`. Port 8443 redirected to `/login`, making it the natural starting point for web enumeration. Nmap's service fingerprinting also reported Microsoft HTTPAPI/2.0.

## Initial Access
### Gaining access using default password
Since the endpoint exposed the serial number of the device, I decided to use that no. as the Device password....and it worked!
I gained access to the dashboard.

<img width="1042" height="884" alt="got-access" src="https://github.com/user-attachments/assets/458d11ec-295a-4551-b470-bb7da7a9080b" />

The interface exposed operational details about the connected passport scanner and boarding-pass printer, including firmware versions, serial numbers, connection information, and username/password fields with reveal controls.

### RDP as KioskUser
This was the next trust-boundary failure: access to a peripheral-management interface exposed information useful for accessing the underlying Windows kiosk. I used the recovered Windows credentials to establish an `RDP` session as `KioskUser`.
```bash
xfreerdp3 /v:<machine_ip> /u:KioskUser /p:'<recovered-password>'
```
<img width="1688" height="888" alt="rdp" src="https://github.com/user-attachments/assets/86d4d083-716c-4a7c-bd1c-a6a837c251f8" />
